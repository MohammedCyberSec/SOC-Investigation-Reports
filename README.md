# SOC-Investigation-Reports

This repository documents SOC investigation write-ups and a reusable investigation template that I am developing and applying to security incidents I work through.

## Status

This project is in progress. Investigation write-ups are added only once they have genuinely been carried out.

## Structure

phishing/ will hold investigations into phishing related alerts. authentication-attacks/ will hold investigations into authentication and identity based attacks. powershell/ will hold investigations involving suspicious PowerShell activity. malware/ will hold investigations into malware related incidents. templates/ contains a reusable incident investigation template used to structure each write-up.

## Skills being developed

Incident response, threat hunting, log analysis, and MITRE ATT&CK mapping.
